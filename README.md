# 📩 Spam Detection System using NLP and Machine Learning

## 📌 Overview

This project implements a **Spam Detection System** using **Natural Language Processing (NLP)** and **Machine Learning** techniques to classify messages as *spam* or *ham*.

---

## ⚙️ Features

* Text preprocessing (cleaning, tokenization, stopword removal, stemming)
* Feature extraction using Bag of Words (BoW) and TF-IDF
* Classification using Naive Bayes
* High accuracy and efficient performance

---

## 🛠️ Technologies Used

* Python
* Pandas, NumPy
* NLTK
* Scikit-learn

---

## 🚀 How It Works

1. Load dataset
2. Clean and preprocess text
3. Convert text into numerical vectors
4. Train machine learning model
5. Predict whether a message is spam or not
